# Feature plan

Issue: ORB-127
Review verdict: PASS

## Outcome

Create a development AppInstance as one resumable operation that selects any compatible PHP runtime from its source, provisions its sole private Route, aligns Laravel configuration when detected, and returns the active HTTPS endpoint through Gateway, SDK, and CLI without an application health gate.

## Code boundaries

In:

- `apps/gateway/database/migrations/*app_instance_route*`, `apps/gateway/app/Models/{AppInstance,Route,RouteTarget}.php`, and `apps/gateway/app/Domain/{AppInstances,Routes}/**`: add an upgrade migration that inventories every existing AppInstance-to-Route association before its first schema mutation, reports all invalid active AppInstances together, preserves valid identities, enforces at most one Route per AppInstance under concurrent writers, and requires one Route when an AppInstance becomes active. Extend the pending-only Route lifecycle to pending and active, allow a source-resolved AppInstance to receive its initial target, retain bounded failed-step and error-code evidence while pending, and store closed internal provisioning-step evidence without adding caller-supplied PHP state.
- `apps/gateway/app/Actions/AppInstances/{CreateAppInstanceAction,RemoveAppInstanceAction}.php`, `apps/gateway/app/Actions/Routes/CreateRouteAction.php`, `apps/gateway/app/Data/AppInstances/AppInstanceData.php`, `apps/gateway/app/Http/Controllers/Api/AppInstancesController.php`, and `apps/gateway/app/Domain/AppInstances/**`: replace the post-activation Route hook with one development provisioner. It resolves explicit or generated hostname feasibility before source or runtime mutation, keeps the managed-clone `reserved -> checkout_prepared -> source_resolved` transitions, creates or recovers the sole pending Route, resumes from verified step evidence, and marks Route and AppInstance active together only after every required projection succeeds. It returns the bounded Route, hostname, and derived HTTPS URL and guards active removal before source deletion or target detachment.
- `apps/gateway/app/Domain/AppInstances/{AppInstancePhpVersionCatalog,*SourceClassification*,*PhpRuntime*}`, `apps/gateway/app/Infrastructure/AppInstances/*SourceClassification*`, and `apps/gateway/tests/Feature/Infrastructure/AppInstances/PhpRuntimeSelectionTest.php`: make `AppInstancePhpVersionCatalog` the one finite, code-owned source of selectable development runtimes, ordered as `['8.5', '8.4']`. Read a regular non-symlink `composer.json` without running project code, parse it with the installed Composer Semver library, and select the first catalog member that satisfies the PHP platform constraint. Use PHP 8.5 when the PHP project has no PHP constraint and select no PHP for source without Composer metadata. Invalid constraints and constraints below, between, or above all candidates fail with `app-dev.php_version_unsupported`; if the selected candidate is unavailable when `RemotePhpPackageManager` verifies packages against the pinned Sury source, fail with `app-dev.php_package_source_unavailable`. Both failures happen before runtime or DNS publication and retain source, pending Route, and selection evidence for retry. `SupportedPhpVersion` remains the broad validation rule for legacy Instance and Workspace inputs, not this finite selector. The selected value is internal derived retry evidence and never an AppInstance input or public response field.
- `apps/gateway/app/Domain/AppInstances/*Laravel*`, `apps/gateway/app/Infrastructure/AppInstances/*Laravel*`, and `apps/gateway/tests/Feature/Infrastructure/AppInstances/LaravelUrlConfigurationTest.php`: classify Laravel only from a regular non-symlink `artisan` file plus strict `composer.json` evidence with one unambiguous `laravel/framework` declaration. Treat absence of both markers as non-Laravel and refuse partial, malformed, conflicting, duplicate, symlinked, or unsafe evidence before configuration or publication. Atomically update exactly one `APP_URL=https://<hostname>` and static cached `app.url`, preserve all unrelated bytes and later operator changes, and keep environment values out of argv, invocation state, result text, errors, responses, activity, and debug output by using stdin or protected mode-0600 files.
- `apps/gateway/app/Domain/Routes/**`, `apps/gateway/app/Infrastructure/Routes/**`, `apps/gateway/app/Infrastructure/AppDev/{AppDevCaddyConfigRenderer,AppDevCaddyPublisher,AppDevDnsConfigRenderer,AppDevSite,AppDevSiteRepository,DnsmasqPrivateDnsManager,RemoteAppDevPhpFpmManager}.php`, and `apps/gateway/app/Providers/AppServiceProvider.php`: add a typed initial private projection inventory for AppInstance workload and Router sites. Node scope serves the configured document root on the workload Node. Cluster scope preserves the Route hostname as HTTP Host and TLS server name through the Router, selects a reachable configured LAN path without fallback and otherwise WireGuard, and uses the local PHP-FPM socket rather than self-proxying when roles co-locate. Compose AppInstance fragments with legacy sites in the one Caddy service per Node, publish separate workload and Router keys and certificates through protected files, validate the workload leaf, and publish exact Gateway DNS last.
- `apps/gateway/app/Actions/Clusters/{SetClusterRouterAction,ClearClusterRouterAction}.php`, `apps/gateway/app/Infrastructure/Nodes/Roles/{RouterRoleBaseline,NativeRoleBaselineConverger,NodeRolePrerequisiteCommandFactory}.php`, `apps/gateway/app/Infrastructure/Nodes/{NodeBootstrapPackageCatalog,NodeRoleServiceCatalog}.php`, `apps/gateway/tests/Feature/Api/ClusterRouterTest.php`, and focused role baseline and catalog tests: put the protected Router assignment lifecycle through `RoleBaselineConverger`; generic `AddNodeRoleAction` continues to reject Router. Initial set and replacement create or reclaim a provisioning candidate, converge its Caddy, certificate, operating-system, service, and recovery prerequisites before active assignment, and retain `converge:*` failed state for an identical retry. Replacement keeps the old Router active until the candidate baseline succeeds, then atomically makes the candidate authoritative and marks the old assignment for cleanup. Clear and old-Router cleanup run only after the Route guard permits the mutation, use `RoleBaselineConverger::remove`, retain `remove:*` failed state when cleanup fails, and delete the assignment only after cleanup succeeds. Retry completes candidate convergence or prior-baseline cleanup without duplicate assignments; an identical set also completes retained cleanup before returning. Preserve one composed Caddy service when Router and workload roles co-locate, and prove the dedicated Router-only path rather than relying on app-dev role packages.
- `apps/gateway/app/Infrastructure/Firewall/NodeFirewallRuleCatalog.php`, `apps/gateway/app/Infrastructure/Nodes/Roles/NativeNodeRoleFirewallManager.php`, and their focused tests: replace public app-dev listener allowances with the ADR 0033 trust boundary. Admit all protocols and ports on the Orbit WireGuard interface for active WireGuard members, keep Node grants limited to Orbit commands and Gateway API actions, add only the exact registered Router-to-workload LAN path needed for a selected Route, and expose neither Router nor workload Nodes directly on public interfaces. Existing Ingress owns public HTTP and HTTPS entry; this issue does not implement Ingress.
- `apps/gateway/app/Domain/Routes/*Reconciliation*`, `apps/gateway/app/Actions/Routes/{UpdateRouteAction,SetRouteTargetAction,ClearRouteTargetAction,RemoveRouteAction}.php`, `apps/gateway/app/Actions/AppInstances/RemoveAppInstanceAction.php`, `apps/gateway/app/Actions/Clusters/{AttachClusterNodeAction,DetachClusterNodeAction,SetClusterRouterAction,ClearClusterRouterAction,UpdateClusterAction}.php`, and `apps/gateway/app/Actions/Nodes/ProvisionNodeAction.php`: add one closed pre-mutation `route.reconciliation_required` guard for active Route hostname or publication changes, target replacement or clearing, Route or AppInstance removal, Node WireGuard, LAN, TLD, or Cluster-membership changes, Cluster lifecycle or TLD changes, and Router replacement or clearing. Router replacement and clear run this guard before claiming, converging, removing, or deleting any baseline or assignment and recheck it in the authoritative transition. Preserve the complete serving path and both Router baselines on refusal. Identical no-change requests, Node grant mutations, and changes that affect no active Route retain their current behavior.
- `apps/gateway/tests/Feature/Api/{AppInstancesTest,ClusterRouterTest,RoutesTest}.php`, `apps/gateway/tests/Feature/Database/AppInstanceRouteConstraintTest.php`, `apps/gateway/tests/Feature/Domain/{ProvisionDevelopmentAppInstanceTest,RouteMutationReconciliationTest}.php`, and focused tests under `apps/gateway/tests/Feature/Infrastructure/{AppInstances,Routes,Nodes}/**`: prove API shape, preflight and constraint races, source classification, finite PHP selection, Laravel file safety, ordered resume, Node and Cluster topology, protected Router set/replace/clear/retry/recovery, a dedicated Router-only Node, Caddy composition, certificates and secret redaction, WireGuard and LAN firewall policy, publication ordering, injected failures, no-change behavior, and every guarded mutation while preserving source and legacy records.
- `packages/php-sdk/src/Responses/AppInstances/{AppInstanceResponse,AppInstanceRouteResponse,AppInstancesResponse}.php` and `packages/php-sdk/tests/Unit/Requests/Instances/InstanceRequestsTest.php`: map the bounded sole Route, hostname, and HTTPS URL in create, list, show, and removal responses. Keep the existing four AppInstance requests, hostname omission rules, request ID, recursive redaction, diagnostics, TLS policy, and framework-neutral Saloon transport, and add no PHP field or operation.
- `apps/cli/app/Commands/Instances/{CreateInstanceCommand,ListInstancesCommand,ShowInstanceCommand,RemoveInstanceCommand}.php` and `apps/cli/tests/Feature/Instances/InstanceCommandsTest.php`: render Route identity, hostname, and HTTPS URL in deterministic human and JSON AppInstance output without adding a command or option. Keep PHP selection, source classification, Laravel detection, routing, network, and health policy in the Gateway.

Out:

- App source identity and layout remain unchanged beyond the existing managed-clone lifecycle: no stable default-instance identity, existing-source registration, source-default update, checkout migration, or production placement is added.
- Existing active Route changes and removal remain guarded rather than reconciled: no traffic cutover for retargeting, renaming, scope, address, publication, or removal changes; no public Ingress or public DNS-provider implementation; and no multi-target balancing policy is added.
- App setup-step configuration and execution, inferred dependency installation, application health state, and operator deployment commands remain unchanged. Laravel detection owns only the canonical URL files and never runs application code.
- `apps/e2e/**` and `bin/e2e-*` remain unchanged. Implementation expresses live coverage only in `.loop/proof/ORB-127.json` and optional sibling fixtures.
- Legacy Instance and Workspace records, source, hostnames, certificate fields, runtime, API identity, and conversion behavior remain unchanged. Shared Caddy, DNS, PHP-FPM, certificate, and firewall publishers continue to compose legacy projections with AppInstance projections.
- Dependency manifests, unrelated components, GitHub, Linear, discovery state, proof topology promotion, and production release remain unchanged.
