3. Add the scoped Prompts adapter/theme. Retain framework validation/fallback callbacks. Restore output, terminal, theme, cancellation and interaction state for sequential/nested calls. Cancellation/EOF yields a typed internal abort, never a silently accepted default.
4. Add monotonic ProgressDisplay and SpinnerDisplay::during(label, operation), sharing the isolated renderer process and explicit lifecycle. SpinnerDisplay owns short and inner waits, returns the callback value and rethrows its failure after cleanup; command-owned status handling remains unchanged. Use the standard active glyphs, labels and decoration with readable settled plain output. Do not delegate to stock Prompts Spinner, whose separate fork/signal/destructor path does not meet this lifecycle. The isolated renderer receives presentation state only. Keep callbacks/SDK requests in the parent. Keep one renderer as the selected output owner through nested composition. Apply acknowledged presentation updates before admitting the associated callback. Stop and reap the exact renderer before the parent writes outside that compositor. Restore signal handlers/settings, handle startup/IPC/output failure, and avoid broad process killing or Laravel shutdown hooks in the renderer. Plain mode emits complete append-only lines: one honest waiting line before admitted work and a settled outcome. It never emits repeated animation snapshots or cursor movement.
5. Integrate shared command/error/common-entry boundaries. Re-evaluate final bound mode after framework prompt configuration; preserve pre-binding JSON parser errors. No mutable invocation singleton or human frames in help/version/completion/framework JSON.

## Deviations

Implementation review clarified that plain output includes one complete waiting line before slow admitted work, followed by the settled outcome. These are append-only lines, not repeated animation frames. This preserves both immediate liveness and clean pipes.

The shared invocation boundary preserves framework prompt state around setup. Mode detection runs after binding whenever a command uses the shared helper; the adapter scopes those prompts. Existing family fallbacks keep their current owner until their bounded migration. This does not claim family compliance.

Interactive tables also refuse a terminal too short to show complete headers and the selected logical row. This enforces the existing no-clipping requirement without selecting an incomplete record.

Nested terminal recordings found short glyph intervals at renderer restarts. Same-output nesting retains one renderer and applies acknowledged frame updates on its existing animation clock. This preserves parent-only callbacks and single-writer cleanup while meeting the existing cadence criterion. The proof-only identity and byte-order instruments strengthen evidence without changing public command contracts.

Native Solo review found that the terminal counts joined and modifier emoji as four cells, and keycap sequences as one. The renderer now measures ordinary base-character cells without assuming grapheme contraction, while preserving complete graphemes when wrapping. The fixture table minimum is 25 columns, with complete record fallback at 24. The proof width oracle is checked against native cursor-position measurements and rejects the earlier overflowing recordings. This corrects the existing within-borders requirement; no terminal mode negotiation or product contract is introduced.
