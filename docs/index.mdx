Orbit is an AI-first tool for local app development, production hosting, and day-to-day fleet maintenance. One Gateway keeps the record of every machine and application you add. The `orbit` command line is how you, or the coding agent you already use, ask the Gateway to change them.

## How it fits together

```text
Human or AI agent
        ↓
       CLI
        ↓
      HTTP
        ↓
     Gateway
        ↓
       SSH
        ↓
  Managed Nodes
```

The Gateway stores Orbit's data in SQLite, authorizes each action, and applies it to Nodes over SSH. Nodes reach each other over a private WireGuard network. Web traffic takes a separate path through [Routes](/reference/routes).

## Built for humans and agents

Humans and agents use the same commands. Human output is readable in a terminal, and `--json` returns the same result as one structured document with the Gateway request ID. The Gateway records who ran what, so you can read what happened instead of guessing.

Agents get focused, visible, and testable actions rather than unrestricted access. Orbit manages only the machines and resources you explicitly add.
