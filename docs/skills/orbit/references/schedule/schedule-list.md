# schedule:list

List authorized Schedule summaries without command text, or the definitions of one App.

```bash
orbit schedule:list [--app=APP] [--json]
```

| Option | Meaning |
| --- | --- |
| `--app=APP` | List the App's Schedule definitions instead of installed Schedules. |

The list contains only Schedules whose target Node you may address.
