# process:show

Show one App process definition by name, including its UUID and complete specification.

```bash
orbit process:show <name> --app=APP [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `name` | yes | Process definition name. |

| Option | Meaning |
| --- | --- |
| `--app=APP` | Numeric App ID that owns the definition. |
