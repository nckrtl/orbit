---
title: "app"
description: "The old App CLI command family is removed; use project commands instead."
---

The App CLI command family has been removed. Use [`project`](/cli/project) for Project records, including `project:create`, `project:list`, `project:show`, `project:update`, and `project:destroy`.

The Gateway serves repository records at `/api/v1/projects` and publishes Project MCP tools. Update older CLI binaries and clients to use that Project surface.

See [Projects](/reference/apps) and [ADR 0177](/decisions/0177-remove-the-app-compatibility-surface).
