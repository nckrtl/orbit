A Project records one Git repository and the defaults for running it. [Projects](/reference/apps) owns the fields, types, update lifecycle, and error codes. [Applications](/domains/applications) shows how a Project becomes an Instance.

## Commands

| Command | Result |
| --- | --- |
| [`project:create`](#orbit-projectcreate) | Create a Project from a slug, a type, and a repository URL. |
| [`project:list`](#orbit-projectlist) | List Projects. |
| [`project:show`](#orbit-projectshow) | Show one Project. |
| [`project:update`](#orbit-projectupdate) | Change a Project and reconcile its Instances. |
| [`project:destroy`](#orbit-projectdestroy) | Remove a Project. |

Every command accepts `--json`. [`project:excluded-node`](/reference/development-node-exclusions) keeps a Project off selected `app-dev` Nodes.

## orbit project:create

```bash
orbit project:create <slug> <type> <repository> [options]
```

| Argument | Meaning |
| --- | --- |
| `slug` | Unique Project slug. |
| `type` | `monorepo`, `laravel-app`, `laravel-package`, or `node-package`. |
| `repository` | HTTPS or SSH Git URL. |

| Option | Default | Meaning |
| --- | --- | --- |
| `--name=NAME` | the slug | Display name. |
| `--default-branch=BRANCH` | the remote default | Default branch. It must exist on the remote. |
| `--root=PATH` | `.` for package types, `public` otherwise | Repository-relative root that Instances inherit. |
| `--task-check=COMMAND` | `composer check` for `laravel-app` and `laravel-package`, none otherwise | Command that task baselines and handoffs run. |

```bash
orbit project:create acme laravel-app git@github.com:acme/site.git
orbit project:create support laravel-package git@github.com:acme/support.git
orbit project:create node-kit node-package git@github.com:acme/node-kit.git --task-check="vp run check"
```

A retry with the same values returns the existing Project.

## orbit project:list

List every Project with its slug, type, repository, default branch, and root.

```bash
orbit project:list [--json]
```

## orbit project:show

Show one Project with its source defaults, task check, and excluded Nodes. A null task check means tasks run no check command. Human output also lists the Project's Instances with ID, name, environment, Node, domain, and status. In a terminal, selecting an Instance opens `instance:show`.

```bash
orbit project:show <project> [--json]
```

## orbit project:update

Change the fields you pass. The Gateway reconciles affected checkouts, Routes, and runtimes. It never starts a deployment. See [Update a Project](/reference/apps#update-a-project).

```bash
orbit project:update <project> [--type=TYPE] [--slug=SLUG] [--repository=URL] [--default-branch=BRANCH] [--root=PATH] [--task-check=COMMAND] [--clear-task-check]
```

| Option | Meaning |
| --- | --- |
| `--type=TYPE` | New type. |
| `--slug=SLUG` | New slug. Generated domains follow it. Recorded paths stay. |
| `--repository=URL` | New Git URL. |
| `--default-branch=BRANCH` | New default branch for `default` Instances that inherit it. |
| `--root=PATH` | New root for Instances without their own root. |
| `--task-check=COMMAND` | New task check. |
| `--clear-task-check` | Remove the task check. Combined with `--task-check`, it returns `app.task_check_conflict`. |

## orbit project:destroy

Remove a Project that has no Instances and no Routes. Its definitions, setup steps, Node exclusions, and update records go with it. A Project with task groups cannot be removed: the request fails with `gateway.unhandled`. See [Remove a Project](/reference/apps#remove-a-project).

```bash
orbit project:destroy <project> [--yes] [--json]
```

The CLI shows the Project and asks for confirmation, with No selected. `--yes` confirms without a prompt and is required for JSON and noninteractive calls.
