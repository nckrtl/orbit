---
title: "instance:deploy-step:list"
description: "List deploy steps in phase and placement order."
---

List deploy steps in phase and placement order. `--json` returns the steps and the `request_id` as one object.

```bash
orbit instance:deploy-step:list <instance> [--json]
```

## Use it when

Use this command to find a step name for another deploy-step command, or to confirm the order after a change.
