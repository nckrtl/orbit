---
title: "node:show"
description: "Show one Node."
---

Show one Node, including its recorded architecture, WireGuard and LAN addresses, roles, and configured apps path. JSON includes the raw `settings` member.

```bash
orbit node:show <node> [--json]
```

| Argument | Required | Meaning |
| --- | --- | --- |
| `node` | yes | Numeric Node ID. |
